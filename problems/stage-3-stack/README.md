# Stage 3 · Stack (and your first classes)

**Goal:** use a stack (a list where you only add and remove at the end, last in, first out) for problems where things have to be matched or undone in reverse order. Also write your first small **class** (a blueprint for objects that bundle data and functions), which you'll need for linked lists, trees and heaps later.

The full primer gets written when you reach this stage, including a short classes primer (`__init__`, attributes, methods, `None`) right before Min Stack.
